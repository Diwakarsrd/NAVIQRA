# NAVIQRA project status

This repository is a renamed early-development distribution of the NAVIQRA v0.5.0 source baseline. Renaming does not imply that all tests, dependencies, DB migrations, mobile clients, scripts, deployment resources, or external integrations have been comprehensively validated under the new namespace.

The Render + Supabase configuration is a deployment reference. It still requires account provisioning, secrets, migration execution, live PostgreSQL verification, security review, load testing, backup/restore evidence, and real deployment smoke tests.

Synthetic provider inventory is non-bookable. No live flight/hotel provider, payment, ticketing, or booking path is included.
