# NAVIQRA v0.5.0 — open infrastructure for interoperable travel agents

**Launch announcement draft**

NAVIQRA is an Apache-2.0 project building provider-neutral infrastructure for travel agents. It provides a deterministic workflow runtime, five-tier traveler memory, a tenant-scoped travel graph, weighted group consensus, provider adapter contracts, audit events, and human-approved recovery workflows.

The v0.5.0 release adds a PostgreSQL deployment path, migration-managed schema, strict production configuration gates, tenant/path isolation checks, request-size controls, safer container defaults, and deployment guidance. PostgreSQL integration and Docker/cloud deployment still need environment-level validation. The sandbox remains synthetic and non-bookable; OIDC/SSO, supplier credentials, observability, and independent security review remain outstanding.

NAVIQRA is designed to complement existing travel marketplaces and distribution systems—not replace their authority over identity, live inventory, pricing, payment, or booking.
